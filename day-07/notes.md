\# Day 7 - AWS Introduction and Global Infrastructure



\## What is AWS?



AWS (Amazon Web Services) is a cloud computing platform provided by Amazon.



AWS provides services such as:

- Compute

- Storage

- Databases

- Networking

- Security

- Analytics



## Why AWS?



AWS allows organizations to use cloud resources without managing physical infrastructure.



Benefits include:

- Pay-as-you-go pricing

- Scalability

- High availability

- Global infrastructure

- Security

- Flexibility



## AWS Global Infrastructure



AWS infrastructure is distributed across different geographical locations around the world.



The main components are:



### Regions



A Region is a physical geographical location where AWS has data centers.



Examples:

- Mumbai

- Singapore

- Frankfurt

- Virginia



Each Region contains multiple Availability Zones.



### Availability Zones (AZ)



An Availability Zone is one or more data centers within an AWS Region.



Availability Zones are designed to provide:

- High availability

- Fault tolerance

- Disaster recovery



Example:



AWS Region

|

|-- Availability Zone A

|-- Availability Zone B

|-- Availability Zone C



\### Edge Locations



Edge Locations are used to deliver content with low latency.



They are commonly used by services such as Amazon CloudFront.



## Important Concept



Region = Geographical area



Availability Zone = Isolated data center location inside a Region



Edge Location = Location used for faster content delivery
