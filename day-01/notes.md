\# Day 1 — Cloud Computing Fundamentals



\## What is a Server?



A server is a computer that provides services or resources to other computers.



\## What is Cloud Computing?



Cloud computing means using computing resources over the internet instead of managing all the physical infrastructure yourself.



\## What is a Cloud Provider?



A company that provides cloud infrastructure and services.



Examples:

\- AWS

\- Microsoft Azure

\- Google Cloud



\## What is AWS?



AWS stands for Amazon Web Services. It is Amazon's cloud computing platform.



\## Why do companies use Cloud?



Companies can use cloud resources without having to purchase and maintain all physical infrastructure themselves.



\## My Understanding



Cloud computing allows companies and developers to use computing resources through the internet when they need them.
