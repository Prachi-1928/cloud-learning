# Day 2 — Client, Server and Communication



## What is a Client?



A client is a device or application that requests a service or resource.



Examples:

- Web browser

- Mobile application

- Desktop application



## What is a Server?



A server is a computer or system that provides services or resources to clients.



## What is a Request?



A request is sent by a client when it wants something from a server.



## What is a Response?



A response is the information sent back by the server to the client.



## Client-Server Model



Client → Request → Server

Client ← Response ← Server



## Real World Example



When I open a website, my browser acts as a client. It sends a request to the website's server. The server processes the request and sends a response back to my browser.
