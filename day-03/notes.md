\# Day 3 — Networking Fundamentals: IP Address and DNS



\## What is an IP Address?



An IP address is a numerical address used to identify and communicate with a device on a network.



Example IPv4 address:



192.168.1.10



\## What is a Domain Name?



A domain name is a human-readable name used to access a website.



Examples:

\- google.com

\- github.com

\- amazon.com



\## What is DNS?



DNS stands for Domain Name System.



DNS translates domain names into IP addresses so that computers can locate the correct server.



\## Domain Name vs IP Address



Domain Name → Easy for humans to remember

IP Address → Used by networks to identify destinations



Example:



google.com

&#x20;   ↓

IP Address

&#x20;   ↓

\## Public IP vs Private IP



Private IP addresses are generally used inside private networks.



Public IP addresses are used for communication across the internet.



Example flow:



Device (Private IP)

&#x20;       ↓

Router

&#x20;       ↓

Public IP

&#x20;       ↓

Internet



\## Practical Commands Used



\### DNS Lookup



nslookup google.com



This command performs a DNS lookup and returns DNS information for the domain.



\### Network Configuration



ipconfig



This command displays network configuration information on Windows.
